# Ideas Backlog (optional)

**Idea** = "this may be valuable" — not yet an approved feature. **Optional** — you can skip ideas and create Draft features directly.

Automations **do not** promote ideas. Promotion is **manual only**.

## Format

Each file: `NNN_short-description.md`

See [idea-template.md](idea-template.md).

## Manual promotion

When ready, ask **specloom-work-creator**: *"Promote idea 001 to a feature"*.

That runs **specloom-work-creator-create-feature**, validates, archives the idea as `promoted`, and creates `docs/features/NNN_*.md`.

## Skills

- Add idea: **specloom-work-creator-create-idea** (optional)
- Promote: user → **specloom-work-creator** only
