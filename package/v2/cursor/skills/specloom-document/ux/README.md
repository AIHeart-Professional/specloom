# UX references

Design / mockup **targets** for Briefs. Not shippable app assets.

## Rules

- Store mockups under `refs/<flow-or-screen>/`
- Briefs list exact paths (or Linear attachment URLs) in **Required Context**
- Implementers read **only** listed refs
- Runtime icons/fonts → **app repo** `assets/` (etc.), listed as Task **Asset Files**

See SpecLoom skill **specloom-ux-refs**.
