# README

The one document guaranteed to be read. Optimise for a stranger in a hurry.

## Order

1. **What it is** — one sentence, no marketing
2. **Why it exists** — the problem, two sentences
3. **Quick start** — commands that work from a clean clone
4. **Configuration** — required env vars, no values
5. **How to develop** — test, lint, build
6. **Where to look next** — links to `architecture/`, `system/`, `workflow/`

## Rules

- Every command must be runnable as written. A README that fails at step one destroys trust in
  everything under it
- Quick start reaches something observable — a running server, a passing test — in under five
  commands
- Link rather than duplicate. A README restating the architecture will be the stale copy
- No badge wall
