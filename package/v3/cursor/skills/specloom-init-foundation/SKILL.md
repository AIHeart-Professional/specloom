# Overview foundation

Overview SoT = **Linear Initiative**. Co-author via dialogue; commit when coverage solid.

## Required sections

Use `overview-template.md` +:

- `planning_mode: high|low`  
- Engineering defaults (languages)  
- GitHub repo URL + `ai-workflow`  
- Standards paths from advisory  
- Phase roadmap table  
- Open Questions  
- Idea disposition matrix  

## Quality bar

**Automation-ready:** `the Loop` can implement Ready Briefs without inventing product rules.  
Confidence on coverage **≥ 99%** before `complete` (or user-accepted holes → those Briefs Backlog only).

Thin one-liners (“has trading”) = **not** solid — planner must keep drilling.

## Idea disposition

| Idea | Disposition | Where |
|------|-------------|-------|
| I1 | Overview / Phase N Brief / deferred / rejected | … |

Every `core` idea mapped or rejected with reason.

## Forbidden

- Invent product requirements user did not accept  
- Skip Open Questions when holes remain but mark Briefs Ready anyway
